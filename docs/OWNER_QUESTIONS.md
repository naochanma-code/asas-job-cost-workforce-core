# คำตอบของโอ๋และสิ่งที่ต้องทำต่อ

อัปเดต 21 กันยายน 2026 หลังได้รับคำตอบครบทั้ง7ข้อ บันทึกคำตัดสินใน [ADR-007](adr/007-owner-decisions-m0-r2.md) แล้ว **ไม่ต้องตอบคำถามเดิมซ้ำค่ะ**

| ข้อ | คำตอบของโอ๋ที่นำไปใช้ | สถานะ |
| --- | --- | --- |
| Q-01 | Admin/PM เห็นคน วันเข้างาน จำนวนวันทำงานและชั่วโมง OT ไม่เห็นยอดเงินใด ๆ; Owner เห็นเงิน รองรับหุ้นส่วน3คนใช้บัญชี Owner แยกกัน | ยืนยันแล้ว |
| Q-02 | ส่วนใหญ่หนึ่ง Project ไม่มีงานย่อย แต่เพิ่มงานย่อยได้เมื่อต้องใช้ | ยืนยันแล้ว |
| Q-03 | ลง OT เป็นชั่วโมงพร้อมวันที่ เลือกย้อนหลังได้ ข้ามเที่ยงคืนก็ใช้วันที่ที่ระบุทั้งรายการ ไม่แยกคิดเพิ่ม | ยืนยันแล้วสำหรับวันที่/ข้ามคืน; เศษชั่วโมงและกรณีไม่มีวันทำงานค่อยคุยก่อนทำระบบจริง |
| Q-04 | ทำสองโครงการในวันเดียว แบ่งโครงการละครึ่งวัน | ยืนยันแล้ว; ใช้ค่าแรง/ค่ากินครึ่งวันตามกติกาเดิม ไม่จ่ายซ้ำสองเต็มวัน |
| Q-05 | ปิดยอดเงินทั้งหมดของ Admin/PM รวมหน้าตั้งงบและค่าใช้จ่าย | ยืนยันสิทธิ์แล้ว; รายละเอียดแบ่งงบงานย่อยยังไม่ถือว่าอนุมัติจากคำตอบนี้ |
| Q-06 | Owner ดูค่าใช้จ่ายแต่ละเดือนและนำรูปบิล/ใบเสร็จ/สลิปค่าใช้จ่ายออกเป็น folder ทั้งเดือนได้ ใช้ SMEMOVE ทำบัญชีแยก | ยืนยันขอบเขตแล้ว; ระยะเก็บจริงยังไม่ได้กำหนด ไม่มีการลบหลักฐานจากคำตอบนี้ |
| Q-07 | โอ๋จะเตรียมการทดลองจริงให้ภายหลัง | รอเมื่อพร้อมทดลองจริง ไม่ขวางการแก้ต้นแบบ |

## สิ่งที่ทีมพัฒนาปรับให้

- ย้ายการตรวจยอด/อนุมัติค่าใช้จ่ายและการตั้งงบไป Owner เพราะ Admin/PM ดูเงินไม่ได้ รวมถึงไม่เปิดรูปบิลที่มีราคาให้ Admin/PM
- Owner3บัญชีใช้สิทธิ์เดียวกันและเก็บว่าใครเป็นคนทำรายการ ไม่จำเป็นต้องใช้บัญชีร่วมกัน
- เพิ่มเลือกรูปจากเครื่อง ดูภาพก่อนส่ง ลบ/เปลี่ยนรูปได้ และโหลด ZIP ที่แตกออกเป็น folder ทั้งเดือนได้ในต้นแบบ
- เติมประเภทรายจ่าย9หมวด ส่วนค่าแรงและ OT คำนวณจากวัน/ชั่วโมง จึงไม่ต้องกรอกเป็นรายจ่ายซ้ำ

ต้นแบบเก็บไฟล์ที่เลือกไว้ในหน่วยความจำของ browser เท่านั้น ไม่มีส่งขึ้น server และ refresh แล้วข้อมูลหาย ใช้ภาพทดสอบแทนบิลจริง

## รอโอ๋ทำอะไรต่อ?

ตอนนี้ไม่ต้องส่งข้อมูลบัญชีหรือเตรียมระบบจริง ขอให้ลองต้นแบบที่ปรับแล้วเมื่อสะดวก โดยเฉพาะเลือกภาพ ประเภทรายจ่าย ลง OT ย้อนหลัง และสลับบทบาทดูว่าข้อมูลตรงหน้าที่หรือไม่ การตรวจต้นแบบยังเป็นส่วนของ Milestone0 ไม่ใช่เปิดใช้งานจริง และยังไม่ถือว่าผ่านการตรวจรับทั้งหมดจากการตอบคำถามครั้งนี้

## เรื่องที่ยังเก็บไว้คุยภายหลัง

OT เศษชั่วโมง/ไม่มีวันทำงาน, วิธีแบ่งหรือเพิ่มงบงานย่อยสำหรับ Owner, เดือนอ้างอิงของเอกสารและระยะเก็บจริง และรายละเอียดผู้ร่วมทดลอง ยังไม่ใช่เหตุให้หยุดปรับต้นแบบรอบนี้ ไม่ถามย้ำเรื่องสิทธิ์เงินหรือ OT ข้ามวันที่โอ๋ตอบแล้ว

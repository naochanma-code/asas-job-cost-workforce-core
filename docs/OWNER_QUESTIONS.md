# คำตอบของโอ๋และสิ่งที่ต้องทำต่อ

อัปเดต21กันยายน2026 รอบ3 บันทึกคำตอบแล้วใน [ADR-008](adr/008-admin-review-ot-retention.md) **ไม่ต้องตอบคำถามเดิมซ้ำค่ะ**

| เรื่อง | กติกาที่ใช้ตอนนี้ |
| --- | --- |
| Admin | ตรวจ แก้ไข และอนุมัติจำนวน รายละเอียด จำนวนเงิน และรูปที่ช่างส่งได้ทีละรายการ ไม่เห็นต้นทุนรวม ยอดใช้ไปรวมของโครงการ ค่าแรง หรือยอดPayroll |
| PM | ดูคน วันเข้างาน วันทำงานและOTตามโครงการ ไม่เห็นเงินหรือรูปบิล; คำตอบล่าสุดเปลี่ยนเฉพาะAdmin |
| Owner | หุ้นส่วน3คนมีบัญชีแยก ดูเงินและยอดรวมได้ เก็บว่าใครทำรายการ |
| วันทำงาน/OT | Adminอนุมัติแล้วผ่านเลย ไม่ต้องให้Ownerตรวจเวลาซ้ำ ปิดเดือนแล้วระบบสรุปเงิน Ownerตรวจเฉพาะยอดจ่าย |
| Project/งานย่อย | ทำงานครบได้โดยไม่มีงานย่อย เพิ่มภายหลังได้เมื่อต้องใช้ |
| OT | ระบุวันที่ย้อนหลังและชั่วโมงเต็ม/ครึ่งชั่วโมง เช่น2.5ได้ ไม่รับเศษนาที ข้ามเที่ยงคืนก็ใช้วันที่ที่เลือกทั้งรายการ |
| ทำงานสองโครงการ | แบ่งโครงการละครึ่งวัน รวมหนึ่งวัน ไม่จ่ายซ้ำสองเต็มวัน |
| หลักฐานบัญชี | Ownerดูค่าใช้จ่ายรายเดือนและโหลดfolderรูปบิล/ใบเสร็จ/สลิปได้ เก็บหลักฐาน2ปี ใช้SMEMOVEแยก |
| การทดลองจริง | โอ๋เตรียมเมื่อพร้อม ยังไม่ถือว่าผ่านการตรวจรับจากการตอบคำถาม |

ตอนนี้ไม่มีคำถามที่ต้องตอบเพื่อให้ปรับต้นแบบต่อค่ะ เมื่อสะดวกลองให้ช่างส่งบิล แล้วสลับAdminแก้เงิน/รูปและอนุมัติ ลองOT2.5ชั่วโมงด้วย

เรื่องที่ค่อยคุยก่อนทำระบบจริง: OTที่ไม่มีวันทำงานคู่กัน, วิธีแบ่งงบงานย่อย, เดือนอ้างอิงรายงาน และวันเริ่มนับอายุหลักฐาน2ปี (ทีมเสนอเริ่มวันที่เก็บไฟล์) ไม่ต้องยืนยันระยะ2ปีหรือสิทธิ์Adminซ้ำ

ต้นแบบเก็บไฟล์ในbrowserเท่านั้น Refreshแล้วหาย ไม่มีupload serverหรือระบบเก็บ2ปีจริง ใช้ภาพทดสอบค่ะ

# คำถามและข้อขัดแย้งสำหรับ Owner

## โอ๋ต้องทำอะไรตอนนี้?

**ตอนนี้ขอคุยเพียงข้อ Q-01 ก่อน ไม่ต้องตอบทั้ง 7 ข้อพร้อมกันค่ะ** เอกสารเดิมใช้ศัพท์สำหรับทีมพัฒนามากเกินไป ตารางด้านล่างจึงมีคำอธิบายภาษาง่ายเพิ่มให้ โดยยังไม่ได้ถือว่าโอ๋ตกลงข้อเสนอใดแล้ว

**คำถามแรก: ให้ฟ้า/Admin และผู้ดูแลโครงการ (PM) เห็นข้อมูลเงินได้แค่ไหน?**

ข้อเสนอคือให้เห็นยอดค่าใช้จ่าย เช่น ค่าน้ำมัน ค่าวัสดุ พร้อมงบของหมวดเหล่านั้น และเห็นจำนวนวันทำงาน/ชั่วโมง OT ของช่าง แต่ไม่เห็นอัตราค่าแรง ยอดค่าจ้าง หรือยอดต้นทุนรวมที่รวมค่าแรง ส่วนโอ๋เห็นทั้งหมด

เหตุผลที่ต้องถาม: ถ้าเห็นต้นทุนรวม 10,000 บาท และรู้ว่าค่าวัสดุ/ค่าเดินทางรวม 6,000 บาท ก็อาจลบออกจนรู้ว่าค่าแรงรวม 4,000 บาทได้ แม้ไม่ได้เปิดหน้าค่าจ้าง ตัวเลขนี้เป็นตัวอย่างสมมติเท่านั้น

โอ๋ตอบในแชทได้ว่า **“ใช้ตามที่แนะนำ”** หรือบอกว่า **“อยากให้ฟ้า/PM เห็นข้อมูลเพิ่มคือ…”** หากข้อมูลที่อยากให้เห็นอาจเปิดเผยค่าจ้าง เราจะคุยจุดนั้นต่อก่อนกำหนดสิทธิ์จริง

นอกจากตอบคำถามทีละข้อแล้ว **ก่อนจบ Milestone 0 จะขอให้โอ๋ลองกดต้นแบบตามงานตัวอย่าง 7 งาน** เพื่อดูว่าคำศัพท์และขั้นตอนเข้าใจง่ายหรือไม่ เช่น ลงวันทำงาน ส่งค่าใช้จ่าย และตรวจสรุปค่าจ้าง ยังไม่ใช่การใช้ระบบจริง โอ๋ไม่ต้องอนุมัติเอกสารทางเทคนิคทั้งหมดหรืออนุญาตให้เปิดใช้งานจริงในตอนนี้

ทีมพัฒนายังแก้เอกสารและต้นแบบส่วนที่ไม่ติดคำตอบต่อได้ และยังไม่เริ่ม Milestone 1 จนกว่าจะตรวจขั้นตอนตามที่กำหนดใน Master Prompt

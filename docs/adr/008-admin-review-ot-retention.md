# ADR-008 — Admin ตรวจรายรายการ, เวลาอนุมัติครั้งเดียว, OT ครึ่งชั่วโมง, หลักฐาน 2 ปี

> สิทธิ์ส่งรายการและPMเห็นexpenseของตนถูกปรับต่อโดย [ADR-009](009-delegated-entry-and-expense-review.md); ข้อความรอบ3ด้านล่างเก็บเป็นประวัติ

วันที่ 2026-09-21 · Owner: โอ๋ · สถานะ Accepted ตามคำตอบรอบ3ใน task นี้

แทนที่ ADR-007 เฉพาะสิทธิ์ Admin, ขั้นตอนตรวจเวลา, หน่วย OT และระยะเก็บหลักฐาน ไม่ขยายสิทธิ์ PM และไม่ยกเลิกสิทธิ์ Owner จัดการอัตรา/ยอดสรุปค่าจ้าง/อนุมัติจ่าย

## คำตัดสิน

1. Admin ตรวจ แก้ไข และอนุมัติค่าใช้จ่ายที่ช่างส่งได้: วันที่ ประเภท จำนวน/หน่วย (ถ้ามี) รายละเอียด จำนวนเงิน และไฟล์หลักฐาน โดยเก็บก่อน/หลัง ผู้แก้ เวลา และเหตุผล การแก้หลังอนุมัติใช้ revision/reversal ตามกติกาเดิม ไม่แก้ ledger เงียบ
2. Admin เห็นยอดเงินและบิล **รายรายการ** เท่านั้น ไม่เห็น Budget, Actual, Project total, ยอดรวมใช้ไป, Remaining, Profit, ค่าแรงหรือ Payroll รวมถึง export/report ที่รวมยอดหรือเปิดเผยอัตราค่าแรง PM ยังคงไม่เห็นเงิน/บิล เพราะ Owner เปลี่ยนสิทธิ์เฉพาะ Admin
3. วันที่และ OT ผ่านเมื่อ Admin อนุมัติ ไม่สร้างคิวให้ Owner ตรวจเวลาอีกรอบ ตอนปิดเดือน Admin กดปิดข้อมูลเวลา ระบบ freeze source set และคำนวณสรุปค่าจ้างอัตโนมัติ Owner ตรวจเฉพาะเงิน/รายการเพิ่มหักและอนุมัติ/lock/จ่ายตาม baseline เดิม; OWNER_REVIEW หมายถึงตรวจยอดเงิน ไม่ใช่ตรวจ source เวลา
4. OT รับจำนวนชั่วโมงบวกที่เพิ่มทีละ 0.5 เท่านั้น เช่น 0.5, 2, 2.5, 8 ไม่รับ 2.25, 2.1, เศษนาที, 0 หรือค่าติดลบ ห้ามปัด input ผู้ใช้ให้ผ่านเงียบ สูตรยังปัด hourly rate บาทเต็มก่อนคูณ hours: ปกติ970 →243 ×2.5 =607.50; วันหยุด364 ×2.5 =910
5. หลักฐานบัญชีเก็บ 2 ปีแทน7ปี ปรับนโยบายและdesignเท่านั้นใน M0 ไม่ลบไฟล์จริงหรือสั่ง lifecycle ของบริการจริง

## ข้อจำกัดที่ต้องอธิบายตรงกัน

Admin ที่อ่านบิล/ยอดทุกรายการอาจรวมยอดค่าใช้จ่ายเหล่านั้นด้วยตนเองได้ คำตัดสินนี้ควบคุมไม่ให้ระบบแสดง/ส่งยอดรวม ไม่สามารถอ้างว่าไม่อาจอนุมานผลรวมใดเลย ส่วนค่าจ้างยังไม่เปิดเผยจาก source rate/financial projection

Monthly money report/ZIPรวมทั้งเดือนยัง Owner-only ตามสิทธิ์เดิม Admin เปิดหลักฐานต่อรายการที่กำลังตรวจได้ ไม่ขยายเป็น bulk export โดยอัตโนมัติ

## Design consequences

- Server ต้องแยก expense-review projection จาก Project aggregate/Payroll projection; raw file/notesอนุญาตเฉพาะexpenseที่มีสิทธิ์ ไม่มี financial fields จาก Work/OT
- OT contract เป็น hours:decimal พร้อม CHECK(hours>0 AND hours*2 เป็นจำนวนเต็ม); ไม่ต้อง start/end หรือแบ่งเที่ยงคืนตาม ADR-007 กรณี OT ไม่มี Work ยังเป็นข้อผิดปกติให้ Admin ตรวจ ไม่ต้อง Owner ตรวจเวลาซ้ำ
- จำนวน/หน่วยของexpense optional และไม่คำนวณยอดแทนจำนวนเงินที่ผู้ส่งระบุ ไม่เปลี่ยนสูตรค่าแรง
- Retention design default: binary แต่ละฉบับนับ2ปีปฏิทินจาก stored_at; บันทึก retain_until/lifecycle audit, ไม่ลบ cost/payroll ledger ตามรูปที่หมดอายุ วันที่เริ่มนับเป็นรายละเอียดออกแบบที่เปิดให้ทบทวนก่อนproduction ไม่อ้างว่า Owner ระบุเอง
- รักษา metadata/hash/ประวัติพออธิบายไฟล์ที่หมดอายุ; ในระบบจริง export copies/backupsต้องมีแผนเดียวกัน ส่วนไฟล์ที่Ownerดาวน์โหลดไปเองอยู่นอกการลบของCore ไม่มี lifecycle worker ในต้นแบบ

## Acceptance

Admin แก้จำนวน/หมายเหตุ/ยอดและภาพก่อนอนุมัติได้ เห็นแค่ยอดรายรายการ ไม่มี Project total; PM ไม่เห็นเงินหรือภาพ; Admin approve Work/OT แล้ว sourceเป็นAPPROVEDทันทีและปิดข้อมูลเวลาได้โดยไม่มีปุ่มส่งOwnerตรวจเวลา; Owner เห็นสรุปการเงินพร้อมอนุมัติจ่าย ไม่ต้องapprove Work/OTอีก; OT2.5ผ่านแต่2.25ไม่ผ่านทุกvalidation; policyระบุ2ปี ไม่มีข้อความ7ปีเป็นค่าปัจจุบัน
